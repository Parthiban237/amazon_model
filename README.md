# 🛒 Amazon Clone Website

A responsive Amazon-inspired e-commerce website built using **HTML, CSS, and JavaScript**. This project recreates the core shopping experience of Amazon with multiple pages and clean UI design.

## 🚀 Live Features

- 🏠 Home Page
- 🔍 Product Search Bar
- 🛍️ Shopping Cart
- 💳 Checkout Page
- 📦 Orders Page
- 🚚 Order Tracking Page
- 📱 Responsive Design
- 🎨 Amazon-like User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
